# Портфолио — Егор (сайты и Telegram-боты)

Одностраничный лендинг на HTML, CSS и JavaScript без фреймворков.

## Как открыть сайт

1. Откройте файл `index.html` в браузере (двойной щелчок или перетащите файл в окно Chrome / Edge / Firefox).
2. Либо запустите локальный сервер из папки проекта:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Telegram

В текстах указано **@твой_юзернейм**, все ссылки ведут на `https://t.me/твой_юзернейм`.

**Важно:** в реальном Telegram логин может содержать только **латинские буквы, цифры и нижнее подчёркивание**. Перед публикацией замените во всём **`index.html`** подстроку `твой_юзернейм` на свой настоящий username (латиницей), без символа `@`, и обновите подпись `@твой_юзернейм` в блоке контактов.

Удобно найти все вхождения поиском по файлу: `t.me/` и `@твой`.

Почту можно изменить в блоке контактов (`mailto:` и видимый текст).
